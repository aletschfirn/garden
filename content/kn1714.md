title: Keenetic Extra (KN-1714)
---

Just. Don't. Buy. It. No, but seriously, WHY would you buy a router with MT7628AN, 128mb RAM and 32mb of flash memory for a price of Keenetic Viva, when it's USB can only be used for **modems**... This is so awkward thing to do by Keenetic.

Tech:

- 1 USB 2.0
- MT7628AN SoC
- 128mb RAM
- 32mb Flash

Comes with KeeneticOS by default, which is a nice system for routers, but the thing is that USB port is software-locked. Only way to use it for USB-drives is to use OpenWRT made for Zyxel Keenetic Extra II... And I would use it, if it didn't had mt76 driver and couldn't use 5gHz radio (.dts file probably not accurate. But the one from KN-1713 just doesn't boot at all)

While I have wanted to make custom version of KeeneticOS using Keenetic-SDK, it just won't work inside web-interface at all. Not USB storage app nor opkg in system components :/ I think it might be somewhat connected with make menuconfig thing but I couldn't verify it. Maybe will try something later but not sure what exactly is the problem.

Another problem is... Device Tree. Mostly it makes it bad for OpenWRT only, since 5GHz radio won't show up at all no matter what I try. Not sure if it is fully related to dts because I couldn't find any path to it inside ZyXel's dts file on OWRT git, but there is on KN-1713 dts, so it can be any related? Not sure still.
